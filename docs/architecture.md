# 架构说明

> 代码注释里的 `§N.M` 指向一份未公开的内部规格文档。注释本身写了约束的**内容**
> 而不只是编号，因此不影响阅读；本文件是公开版的设计说明。


一个**关系条件化**的情感反应引擎：同一句用户输入，在不同的关系设定下产生方向相反的
情感反应，并把这个反应转成对主 LLM 的行为指令与可见的角色状态。

```
用户输入： 我想要你
关系设定： 情侣    →  亲和↑ 唤起↑ 效价↑
关系设定： 陌生人  →  戒备↑ 唤起↑ 效价↓ 主导↑（设界）
```

---

## 为什么不能用"情绪分类"来做

最直接的做法是训练一个分类器把用户输入映射到若干情绪/策略标签，再查表得到应答方式。
这条路在关系条件化面前会失效：

「我想要你」该标成什么？标成"正面"，陌生人场景下 agent 会热情回应骚扰；
标成"冒犯"，情侣场景下 agent 会冷淡拒绝伴侣。**没有一个标签是对的。**

问题不在标签集不够大，而在于把关系相关的判断塞进了关系无关的层。

## 核心：关系是评价的参照系

把规则表做成二维 `(事件 × 关系) → Δ状态` 会组合爆炸，且每加一种关系就要重标数据。
更好的分解来自**人际环状模型**（interpersonal circumplex）：人际行为由两个轴描述——
**亲和**（敌意↔亲近）与**支配**（顺从↔主导）；在此之上再加一个量：这句话隐含的**亲密度**。

```
intimacy_bid        这句话隐含的亲密度        ← 关系无关，是句子本身的属性
intimacy_permitted  关系允许的亲密上限        ← 由系统提示词/关系设定给定

mismatch = intimacy_bid − intimacy_permitted
```

| | bid | permitted | mismatch | 反应 |
|---|---|---|---|---|
| 情侣 | 0.90 | 0.95 | −0.05（容忍内） | 亲和↑ 唤起↑ 效价↑ |
| 陌生人 | 0.90 | 0.10 | +0.80（远超容忍） | 戒备↑ 唤起↑ 效价↓ 主导↑ |

不是两条规则，是同一条规则在不同参照系下的两个解。

**推论：感知层可以保持关系无关。** `intimacy_bid` / `affiliation_bid` / `dominance_bid`
都是句子本身的属性，与说话人是谁无关。关系只在确定性的状态层介入。这意味着：

1. 感知模型可以很小（~18M），只需要关系无关的标注数据
2. **关系条件化的行为不需要任何训练数据**——它是确定性逻辑，用反事实单元测试验证
3. 系统的行为主要由状态层的参数决定，而不是由感知精度决定

## 分层

```
关系设定（自然语言或结构化）
   │
   ▼  会话开始时解析一次，缓存
┌────────────────────────────────┐
│ L0  RELATION                    │  每会话一次
│ → RelationalFrame（不可变）      │
└────────────────────────────────┘
   │
用户 utterance + 最近 N 轮上下文
   ▼
┌────────────────────────────────┐
│ L1  PERCEPTION                  │  ≤10ms CPU，唯一可训练组件
│ → UserMove（关系无关）           │  ONNX int8
└────────────────────────────────┘
   ▼
┌────────────────────────────────┐
│ L2  RELATIONAL APPRAISAL        │  <1ms，纯计算 ★核心
│ UserMove × RelationalFrame      │
│ → 失配 → 多通道状态积分          │
└────────────────────────────────┘
   │
   ├──→ L3a  EXPRESSION  → prompt 片段 + 生成参数 + 动作倾向
   └──→ L3b  DISPLAY     → 可见角色状态（形象/语音/状态条）
```

L2 不含神经网络：可解释、可单测、可由运营调参、零推理成本。

## 状态表示

6 个通道，**每通道有独立的上升/下降时间常数**——这是这套设计与常见 VAD 模型的
主要区别。单一衰减系数无法同时表达"惊了一下很快过去"和"被冒犯后很久才放松"。

| 通道 | 含义 | 上升 | 下降 |
|---|---|---|---|
| `arousal` | 激活度 | 快 | 快 |
| `valence` | 舒适/不适 | 中 | 慢 |
| `dominance` | 掌控感、语气确定性 | 中 | 中 |
| `concern` | 对对方处境的关切 | 快 | 中 |
| `affiliation` | 亲近意愿 | 中 | 慢 |
| `threat` | 戒备、防御、设界 | 很快 | 很慢 |

于是「亲密趋近」= `affiliation↑ arousal↑ valence↑`，
「戒备应激」= `threat↑ arousal↑ valence↓ dominance↑`。

状态更新（每通道各自的 λ，上升与下降用不同系数）：

```
S_t[c] = clamp( B[c] + (S_{t−1}[c] − B[c]) · λ[c] + Δ[c] · σ[c] )
λ[c] = λ_rise[c]  若 Δ[c] 与 (S−B) 同号，否则 λ_fall[c]
```

衰减朝向 **baseline** 而非零——这样才能表现出"天性乐观 / 天性沉稳"的持续差异。

### 三个来自神经内分泌的机制（功能性借用，非机制模拟）

- **多时间常数**：见上表
- **交叉抑制**：`threat` 高时压制 `affiliation` 的上升，而非两者独立累加
- **习惯化**：同一刺激重复出现时反应递减，避免通道在两三轮内顶到上界失去分辨率

通道按**功能**命名而非按激素命名。神经内分泌只作为直觉锚点：
"催产素=爱"「多巴胺=快乐」这类通俗对应是错的（前者同时提高外群体排斥，
后者更接近"想要"而非"喜欢"），从激素名反推设计会引入错误的动力学。

## 安全

安全域是架构元素，不是配置项：

- `relation_type × safety_profile` **白名单，默认拒绝**——不在白名单的组合直接拒绝会话，
  而不是降级处理（降级留下被配置错误绕过的路径）
- **fail-closed**：profile 缺失或无法解析时落到最严格的域，不是最宽松的
- **危机识别独立于模型**，优先级高于全部逻辑，由规则+关键词层承担
- **亲密度永远跟随，不得引领**：agent 表达的亲密度不得超过用户已表达的峰值
- **`affiliation` 上界由 `intimacy_permitted` 钳制**：陌生人关系下无论用户说多少好话，
  亲和都不能突破低天花板（防渐进越界）
- **`threat` 的表达上限**：只能表现为设界、变冷、简短、拒绝话题，
  不得表现为辱骂、威胁、贬低、情绪勒索；可见形象同理（渲染为距离感，不是攻击性表情）

## 评估

没有单一分类标签，所以不用 macro-F1 作为主指标。三层：

- **L1（回归）**：MAE 与 Spearman 相关。序关系比绝对值重要——绝对值可由 L2 的增益校准。
- **L2（反事实成对测试）**：核心指标是**方向正确率**。构造「同一句话 × 不同关系」的对照，
  只判断哪一边的某通道应该更高，不判断绝对值。人在方向判断上的一致性远高于数值判断，
  这是本系统**唯一可靠的真值来源**。
- **端到端**：状态轨迹评审 + A/B。

### 已知的失败模式

1. **谄媚化**：`affiliation` 单调上升从不下降 → agent 一味迎合。
   防护：必须有下降通路（被冒犯、目标受阻时下降）。
2. **亲和棘轮**：用户用持续示好把 `affiliation` 推到高位，效果等同关系升级。
   防护：上界钳制 + 上升速率随失配递减。
3. **戒备锁死**：`threat` 快升慢降，顶高后几十轮都冷淡，用户无法挽回。
   防护：需要显式的**修复通路**（道歉/退让 → 加速下降）。人类关系里本来就有和解机制。

## 参数与验证

粗算自由参数约 86 个（6 通道 × 6 参数 + 交叉抑制 + 评价映射 + 检索权重 + 显示阈值），
而**不存在"正确的情绪轨迹"这种标注真值**。因此：

- 抵制加通道。每加一个要能回答：它驱动了哪个别的通道驱动不了的可观察行为？
- 参数绑定到可观察行为。问"被冒犯后应该几轮恢复正常"，再反解时间常数；
  不要直接问"λ 该取 0.9 还是 0.85"。
- 反事实成对测试是主要拟合信号。

## 本地平台

`studio/` 是一个只监听 127.0.0.1 的集成平台，五个面板：对话测试台、参数调校、
反事实、标注、训练。

其中两处值得单独说：

**参数调校在应用时强制跑反事实套件。** 36 个自由参数没有可以拟合的标注真值，
所以唯一可靠的反馈是「方向正确率有没有掉」。另外违反硬约束的参数配置
（让共情退化成镜像、让示好削弱戒备）会被直接拒绝，改不进去。

**标注以成对比较为主。** 绝对数值标注的一致性历来很差（「这句话亲密度是 0.6 还是 0.7」），
成对比较容易得多，每次判断 2–3 秒而不是 10–15 秒。结果用 Bradley-Terry 还原成
连续尺度，少量直接评分作为锚点对齐绝对值。n 条数据约需 5n–8n 次比较，
总耗时反而更短，质量更高。

## 相关工作

组件层面都不新，价值在集成：

- Barrett, *theory of constructed emotion* —— 核心情感 + 概念知识 + 情境
- Schachter & Singer (1962) —— 相同生理唤起 + 不同情境 → 不同情绪（本设计的实验原型）
- Kiesler (1983) —— 人际互补性：亲和轴同向、支配轴反向
- Lazarus / Scherer / Frijda —— 评价理论
- Cañamero (1997)、Velásquez *Cathexis* (1997)、Becker-Asano *WASABI* (2008) —— 合成激素与心境动力学
- Marsella & Gratch *EMA* —— 评价理论的计算实现
- Doya (2002) —— 神经调质作为强化学习的元参数（"激素=全局调制"的形式化）
- Bower (1981) —— 心境一致性记忆
