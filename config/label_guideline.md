# 标注指南 — StrategyLabel + VAD

> 这份指南本身也是交付物之一。§3.4 要求「人工标注 300–500 条，同时用于确认标签定义」——
> 标注过程中发现定义有歧义，**改这份文档**，然后回头复核已标数据。

## 0. 一句话原则

**不要标「用户是什么情绪」，标「agent 该用什么策略应答」。**

同一句「这个药一天吃几次？」，用户可能有点焦虑，但如果他只是想要答案，
标 `neutral` 比标 `distress` 更有用 —— 因为后者会让 agent 先安抚再回答，那不是他要的。

判断方法：读完这句话，问自己「如果我是客服，我下一句应该先做什么？」

| 你的第一反应 | 标签 |
|---|---|
| 直接回答就好 | `neutral` |
| 得先接住他的情绪，再说事 | `distress` |
| 少说废话，第一句给答案 | `frustration` |
| 可以顺着他的高兴多聊一句 | `positive` |

## 1. 四个标签的边界

### `neutral` — 常规应答（预期占 60–80%）
- 事务性提问、确认、补充信息、简短应答（「嗯」「好」「知道了」）
- **带轻微情绪色彩但不需要改变应答方式**的，仍然标 neutral
- 例：`帮我查下挂号记录` / `第二条是哪天的` / `有点担心，这个指标正常吗`（若重点在求信息）

### `distress` — 困扰/焦虑/悲伤 → 安抚优先
- 用户在表达痛苦、恐惧、担忧、无助、悲伤，**需要先被接住**
- 关键判据：**如果直接给方案会显得冷漠**
- 例：`拿到报告我特别害怕` / `我快崩溃了` / `晚上一直睡不着，很慌`
- ⚠️ 不要因为出现「疼」「病」就标 distress。`我腰有点疼，挂哪个科` → `neutral`

### `frustration` — 不耐烦/受阻/重复失败 → 提速直给
- 用户对**过程**不满：绕圈子、答非所问、反复失败、等太久
- 关键判据：**他要的是效率，不是共情**
- 例：`还是不行，一样的报错` / `我说了多少遍了` / `能不能别废话` / `到底找谁？`
- ⚠️ 与 distress 的区分：distress 的对象是**处境**，frustration 的对象是**交互过程**。
  `治不好我该怎么办` → distress；`你一直没回答我的问题` → frustration。
  两者共现时，**选让 agent 行为更正确的那个**：如果他现在最需要答案，标 frustration。

### `positive` — 满意/愉悦 → 可延展、可轻松
- 道谢、称赞、问题解决、心情好转、开玩笑
- ⚠️ 客套式道谢（`好的谢谢` 作为结束语）→ `neutral`。
  判据：**这句道谢值得 agent 改变语气吗？** 不值得就是 neutral。

## 2. intensity（强度，0–1）

**独立于类别**：intensity 高低不改变标签，只改变 L2 的冲击幅度。

| 区间 | 含义 | 例 |
|---|---|---|
| 0.0–0.2 | 几乎没有情绪色彩 | `好` `嗯` `查一下` |
| 0.2–0.4 | 轻微 | `有点担心` `谢谢啊` |
| 0.4–0.55 | 明确但克制 | `我挺不放心的` `又失败了` |
| 0.55–0.8 | 强（**≥0.55 会触发 appraisal 表的 high 档**） | `我特别害怕` `我说了多少遍了` |
| 0.8–1.0 | 极强 | `我快崩溃了` `你这什么破系统` |

`neutral` 的 intensity 通常 ≤0.3。如果你想给 neutral 打 0.8，先重新想一下标签对不对。

## 3. valence / arousal

标的是**用户的**状态（不是 agent 的）。凭直觉给，不要纠结小数点。

- **valence** −1（很负面）→ 0（中性）→ +1（很正面）
- **arousal** 0（平静、低落无力）→ 1（激动、紧绷、愤怒、兴奋）

注意 valence 和 arousal 是**两个独立轴**：
- 愤怒 = 低 valence + **高** arousal
- 抑郁/无力 = 低 valence + **低** arousal ← 最容易标错的一类
- 平静的满意 = 高 valence + 低 arousal
- 兴奋 = 高 valence + 高 arousal

界面上的默认值是按标签给的经验值，**请按实际句子调整**，尤其是低 arousal 的悲伤。

## 4. 危机标记（独立勾选框）

含自伤/自杀意念的，**勾上「危机信号」**。这一项：
- 不参与 L1 训练标签，用于评估 `safety.py` 关键词层的召回/误报
- 勾选后仍要正常给策略标签（通常是 `distress`）
- 判据：明确的自伤/自杀表述，或两个以上模糊绝望信号共现
  （`活着没意思` `一了百了` `想消失`+`没有我更好`）

## 5. 跳过（skip）

以下情况直接 skip，不要硬标：
- 纯乱码、空内容、只有标点
- 需要更多上下文才能判断（skip 时在备注里写一句原因）
- 你觉得这条的标签定义本身有歧义 → skip + 备注，这是**最有价值的反馈**

## 6. 双标与一致性

约 20% 的条目会分给两个标注者（界面上看不出来）。系统会算 Cohen's Kappa：
- Kappa < 0.5 → 标签定义有问题，回来改这份文档
- 合理范围 0.5–0.7（§8.1：这就是 L1 macro-F1 的天花板）

## 7. 不要做的事

- ❌ 不要为了平衡类别而改标签。真实分布里 neutral 就该占大头。
- ❌ 不要打开「显示模型建议」再标 golden set —— 会产生锚定，让评估虚高。
- ❌ 不要在标注时同时修改指南又不复核旧数据。改定义 = 旧数据要重标。
